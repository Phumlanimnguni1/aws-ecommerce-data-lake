# MnguniMart Serverless Data Lake on AWS

Overview
This project simulates a real-world enterprise data platform implementation for an e-commerce marketplace, MnguniMart. The objective is to design, build, and automate a complete serverless data pipeline consisting of:

- An **Ingestion Layer** for generating and landing raw cart abandonment data.

- A **Storage Layer** utilizing Amazon S3 for distinct data lake zones.

- A **Processing Layer** utilizing AWS Lambda and Pandas to aggregate and transform raw data.

- A **Consumption Layer** designed to read transformed data and map abandoned products to specific customers for targeted promotional campaigns.

The dataset simulates e-commerce cart abandonment, tracking product IDs, abandonment amounts, and customer IDs to identify which product discounts to send to customers. The implementation follows the architectural guidelines provided in the AWS Data Engineering skillbuilder.

## Data Lake Layers

**Ingestion Layer**

- Utilizes the labFunction-Data-Generator Lambda function.

- Acts as the MnguniMart e-commerce backend application.

- Ingests raw cart abandonment data directly into the S3 raw zone bucket.

- No transformations are allowed at this ingestion layer; it is used purely as the landing zone for raw operational data.

**Storage Layer (Amazon S3)**

- Raw Zone: Stores raw CSV data exactly as generated by the ingestion layer.

- Consumption Zone: Stores the cleaned, aggregated, and transformed datasets ready for downstream business applications.

**Processing Layer**

- Utilizes the labFunction-Data-Processor Lambda function.

- Downloads the raw cart_abandonment_data.csv.

- Uses Python and Pandas to calculate and aggregate the top 50 abandoned products.

- Uploads the transformed cart_aggregated_data.csv to the S3 consumption zone.

**Consumption Layer**

- Utilizes the labFunction-Promotion-App Lambda function.

- Accesses the aggregated data directly from the consumption zone data lake.

- Aggregates the data further by customer ID to generate targeted promotion lists.

## Data Assets & Schemas

Rather than a traditional relational star schema, this data lake utilizes flat files moving through distinct states of refinement:

- Raw Data (cartAbandonmentData.csv)

- customer_id

- product_id

- product_amount

- Aggregated Data (cartAggregatedData.csv)

- product_id

- abandoned_amount (Sum of abandoned amounts per product, isolated to the top 50 highest values)

- Promotional Data (promotionData.csv)

- Aggregated customer-to-product mapping for targeted discount delivery.

---
## Pipeline Execution Flow

- All data loading and transformation is automated using AWS Lambda. The execution flow follows a strict progression:

- Data Generation: The generator function writes the initial payload to the Raw S3 bucket environment.

- Data Processing: The processor function reads from the Raw bucket, applies Pandas transformations, and writes the output to the Consume S3 bucket.

- Data Consumption: The promotion app reads the aggregated data and outputs the final promotional CSV mapping.

---
## Security & Roles

- Data Generator Role: Read/Write access strictly limited to the S3 Raw Zone bucket. Cannot access the Consumption zone.

- Data Processor Role: Read access to the S3 Raw Zone bucket and Write access to the S3 Consumption Zone bucket.

- Promotion App Role: Read-only access to the S3 Consumption Zone bucket to power external marketing logic.

---
## Business Outcomes & Analytical Outputs

- Top Abandoned Products Analysis: Identifies highest-value lost sales opportunities based on total abandoned amounts.

- Customer Promotional Targeting: Maps specific high-value abandoned products back to individual MnguniMart customers, enabling the marketing system to send automated discount codes to recover lost revenue.
